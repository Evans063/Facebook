Meta App Configuration Guide

Configuring Your OAuth Redirect URI

Resolve the exact URL you need to enter into your Meta Developer Dashboard under Client OAuth Settings.

1. Localhost / Local Dev

If running your web backend locally on your computer or mobile terminal (Node.js, Flask, Django, Vite):

http://localhost:3000/auth/facebook/callback

2. Live Domain / Hosting

When deployed on Vercel, Netlify, Render, or your custom domain (HTTPS required by Meta):

https://oasis-hub.com/auth/facebook/callback

3. Frontend JS SDK Flow

If using direct client-side popup login (FB.login), toggle Login with the JavaScript SDK to YES and set:

https://oasis-hub.com

Generate Custom Redirect URI
